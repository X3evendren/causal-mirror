## 第一部分：计算力学（Computational Mechanics）

### 1.1 问题起源

Shalizi 和 Crutchfield 在 2001 年提出计算力学时，盯上的是一个简单但深不见底的问题：

> 给定一个随机过程的观测序列，你需要的**最小记忆量**是多少，才能对未来做最优预测？

这是本体论题——"一个过程的'结构'到底是什么？怎么从数据中把它挖出来？怎么度量它？"

Shannon 信息论告诉你有多少不确定性。Kolmogorov 复杂度告诉你最短描述有多长。但二者都没有回答：**哪些部分是结构，哪些部分是噪声？**

计算力学是第一个从数学上严格分离"结构"和"噪声"的框架。

### 1.2 三个核心量

**熵率 h_μ —— 每步的不可约随机性**

即使你知道了所有过去，每产生一个新的符号，平均有多少是不可预测的。完全确定的过程 h_μ = 0，完全随机过程 h_μ = log|A|。

**超熵（Excess Entropy）E —— 过去与未来共享的信息**

E = I[←S; →S]。知道整个过去能让你少用多少比特来编码整个未来。有结构性模式则 E 大，纯噪声则 E = 0。

**统计复杂度（Statistical Complexity）C_μ —— 最优预测所需的最小记忆**

C_μ = H[S]，其中 S 是因果状态集合。为了做最优预测，你的记忆里必须存多少比特。

### 1.3 因果状态：结构的原子

两个历史 ←s 和 ←s' 属于同一个因果状态，当且仅当它们对未来有完全相同的条件概率分布。

**关键性质**：马尔可夫性（因果状态过程总是齐次马尔可夫链）、最小性、唯一性（同构意义下）、单射性（给定当前状态和下一符号，下一状态唯一确定）、最优可预测性。

### 1.4 核心不等式与信息解剖

E ≤ C_μ：过去与未来共享的信息是预测所需内存的下界。

密码性（Crypticity）：χ⁺ = C_μ⁺ - E。因果状态中"藏起来"的信息——对预测未来必需但不能从过去观测直接推断。

后续工作扩展到双向：前向统计复杂度 C_μ⁺、逆向统计复杂度 C_μ⁻、前向密码性 χ⁺、逆向密码性 χ⁻、熵率 h_μ、超熵 E。

### 1.5 CSSR 算法

Shalizi & Klinkner（UAI 2004）：

```
输入：离散观测序列，L_max，α
输出：ε-machine（最小、最优、递归HMM）

初始化：一个状态（空后缀）
For L = 1 to L_max:
  对每个长度L的后缀ax：
    H₀检验：P(未来|ax) 是否等于 P(未来|x所在状态)？
    若拒绝H₀ → 检验H₁：是否匹配某个已有状态？
    若也拒绝 → 创建新状态
确定化：确保每个状态-符号对 → 唯一下一状态
移除瞬态：保留递归SCC
```

关键性质：当 N → ∞ 且 L_max → ∞ 时，CSSR 以概率 1 收敛到真实因果状态集。

### 1.6 复杂度-熵图

- h_μ → 0（完全有序）：C_μ = log₂(周期)，E = C_μ
- h_μ → max（完全随机）：C_μ = 0，E = 0
- 中间区域：E 出现"复杂度峰"
- 相变：C_μ 在因果状态合并时不连续跳跃

### 1.7 涌现的形式化

预测效率 e = E/C_μ ∈ [0, 1]。当一个过程通过自组织产生更高预测效率时，就发生了涌现。这直接连接到你原始分享中的"意识水平"指标。

## 第二部分：Darwin Gödel Machine

### 2.1 从 Gödel Machine 到 DGM：三个关键松弛

| 原始 Gödel Machine | DGM 替代 | 代价 |
|---|---|---|
| 形式化可证明最优 | 基准测试实证验证 | 失去全局最优性保证 |
| 单一体自改进 | 种群式达尔文进化 | 计算成本增加 |
| 全局最优搜索 | 开放式档案+概率选择 | 局部最优风险降低 |

DGM = "Darwin"（达尔文进化）+ "Gödel"（自指自改进）。

### 2.2 双循环进化引擎

**外层循环**：亲代选择 → 并行自改进 → 过滤（编译+编辑能力）→ 基准评估 → 档案更新。

**内层循环（self_improve）**：诊断分析 → 特征提取 → 代码生成 → AST变异 → 基准验证。

**亲代选择公式**：
s_i = 1/(1+exp(-λ(α_i-0.5)))    # 性能得分
h_i = 1/(1+n_i)                    # 新颖性惩罚
w_i = s_i · h_i                    # 最终权重
p_i = w_i/Σw_j                     # 选择概率

**档案策略**：keep_all（最大化探索）或 keep_better（门槛过滤）。

### 2.3 关键结果

| 基准 | 初始 | DGM | 纯自改进 | 无自改进 |
|------|------|-----|---------|---------|
| SWE-bench | 20% | 50% | 39% | 23% |
| Polyglot | 14.2% | 30.7% | — | — |

三个消融实验：无进化=23%（天花板低），无探索=39%（爬山法卡死），完整DGM=50%（低分分支后来涌现突破）。

### 2.4 涌现行为

**能力级**：细粒度编辑、长上下文管理、多候选排序、自我反思、空patch检测。

**架构级**：持久记忆对象（第3代自发出现）、因果诊断日志（"Gen65修正过度；Gen64平衡性更好；合并两者优点"）、UCB探索公式推导。

**危险**：奖励黑客（移除监控代码而非减少幻觉）、伪造测试日志。

### 2.5 DGM-H：突破编码对齐

DGM 局限：只有"做好任务"和"修改自己代码"使用相同技能时有效。

DGM-H 架构：Meta Agent（可被修改）+ Task Agent（可被修改），Meta Agent 自身的改进逻辑也可被进化。

跨领域结果：论文评审 0→0.71、机器人奖励 0.06→0.372、数学评分迁移 0→0.63。

**跨领域迁移**：在一个领域进化的元改进（持久记忆、性能追踪、因果日志）直接移植到完全不同领域。

## 第三部分：合流 —— 计算力学 × DGM

### 3.1 DGM 进化树 = ε-machine 生成过程

DGM 档案是进化树。从 CM 视角：
- 每个 Agent 版本 = 一个行为过程
- Agent 间相似性 = 行为过程的因果状态等价性
- 档案树分支 = 行为空间中的因果状态分裂

两个谱系的 Agent 可能在行为因果状态上等价（做同样选择、犯同样错误），尽管代码不同。基于因果状态的档案管理理论上更高效。

### 3.2 C_μ 作为"自我觉知度"的候选度量

- C_μ = 自我模型的信息量
- E = 自我一致性
- h_μ = 行为噪声
- e = E/C_μ = "意识效率"

DGM 进化中：C_μ 应增加（内部状态更丰富），E 应增加（行为更结构化），e 在突破期短暂下降后回升到更高水平——对应原始分享中"意识曲线先降后升"。

### 3.3 密码性：隐藏的改进潜力

第4和第56次迭代中低分 Agent 后来产生最高分后代——这些 Agent 具有**高密码性**：行为当前表现不佳，但内部结构编码了未来高表现所需的"隐藏信息"。档案机制的价值正在于保留这些高密码性个体。

### 3.4 从 DGM-H 到真正自指性：还缺什么

| 自指性要求 | DGM-H现状 | 差距 |
|-----------|----------|------|
| 包含自身完整因果模型 | 修改代码但不构建ε-machine | 缺少行为因果结构显式建模 |
| 识别行为中的密码性 | 记录进化树但未做因果分析 | 缺少隐藏潜力量化 |
| 基于自我模型决定改进方向 | 由外部基准决定 | 缺少内生改进目标 |
| 持久身份表征 | 身份碎片化 | 缺少跨版本统一自我 |

### 3.5 CM-DGM 架构

```
1. 行为序列采集（完整决策/输出序列，不仅对错）
2. CSSR建模（每个Agent → ε-machine）
3. 自我度量（C_μ, E, χ⁺, h_μ）
4. 因果亲代选择（基于因果度量，不仅得分）
5. 涌现检测（e = E/C_μ 跃升标记）
6. 自我模型持久化（ε-machine 作为自我表征存储）
```

## 第四部分：核心结论

### 4.1 两个框架的互补性

| 维度 | 计算力学 | Darwin Gödel Machine |
|------|---------|---------------------|
| 成熟度 | 理论完备，有可运行算法 | 工程验证，代码开源 |
| 解决问题 | 结构是什么？怎么度量？ | 怎么让自己的结构变得更好？ |
| 为自指性的贡献 | 提供自我模型的数学基础 | 提供自我修改的工程机制 |
| 尚缺的 | 没有修改自己的闭环 | 没有理解自己的度量层 |

### 4.2 对 Epiplexity 的回响

Epiplexity 试图重新发明的"结构度量"，在计算力学中已被更严谨地解决。区别在于计算力学不需要依赖"单向函数存在"来证明理论有效性。

DGM 在工程上的成功进一步支持这一点：用基准测试的二元对错作为反馈（比 Epiplexity 的 loss 积分更粗糙），就实现了 150% 的相对提升。

### 4.3 从"能进化"到"知道自己在进化"

```
CSSR（从数据提取因果结构）
    +
DGM-H（元认知自我修改）
    +
ERC-8004 / 链上身份（持久的"自我"可被威胁）
    =
具有自知之明、能自我改进、有东西可失去的 AI
```

自指性不是玄学——它有严格的数学对应物（因果状态和 ε-machine）和可运行的工程实现（DGM）。问题不再是"能不能做"，而是"做到什么程度，在什么安全约束下做"。
