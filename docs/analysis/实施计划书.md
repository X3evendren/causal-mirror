# 计划书：Causal Mirror —— 自指性 Agent 原型系统

## Context

基于对计算力学（Shalizi & Crutchfield 2001）、Darwin Gödel Machine（Zhang et al. 2025）、元学习、自我对弈、内在动机五个方向的综合分析，我们识别出了自指性 AI 的技术缺口：**"自知之明"是"自我改进"的前提，但现有的自进化系统（DGM/DGM-H）没有内建自我行为模型**。

计算力学框架提供了这个模型的数学基础——CSSR 算法可以从行为序列中提取因果状态自动机（ε-machine），计算 \(C_\mu\)（内部结构丰富度）、\(E\)（行为一致性）、\(h_\mu\)（行为噪声）——但尚无可用的纯 Python 实现。

本计划的目标：**分两阶段构建 "可以看自己、看懂自己、用看懂的信息改进自己" 的最小可行原型**。第一阶段（路线 C）造"诊断仪"——CSSR 引擎。第二阶段（路线 A）造完整的"Causal Mirror"实验系统。

---

## 技术栈

- **语言**：Python 3.11+
- **核心依赖**：scipy, statsmodels, numpy, graphviz, openai（LLM 调用）
- **任务基准**：GSM8K（小学数学推理，~1.3K 测试题，有标准答案）
- **行为编码**：混合编码方案（动作类型 × 结果质量 = 16 符号）
- **LLM**：通过 API 调用（兼容 OpenAI / Anthropic 格式）

### 1.2 CSSR 核心算法

**Phase 1 — 后缀字典树**（`suffix_trie.py`）

一次扫描 O(N) 构建，记录所有长度 ≤ L_max 的子串及其后续符号频率。每个节点存储：出现次数 `count`、后续符号计数 `next_counts`、子节点引用 `children`。

```python
# 构建伪代码
for i in range(N):
    node = root
    for offset in range(min(L_max, N - i)):
        sym = sequence[i + offset]
        if sym not in node.children:
            node.children[sym] = SuffixTrieNode()
        node = node.children[sym]
        node.count += 1
        if i + offset + 1 < N:
            node.next_counts[sequence[i + offset + 1]] += 1
```

**Phase 2 — 状态分裂**（`splitting.py`）

从空后缀开始（1 个状态），逐层 L=1,2,...,L_max：
- 对每个长度 L 的后缀 `ax`（`a` 是前缀符号，`x` 是长度 L-1 的历史）
- H₀ 检验：`P(未来 | ax)` 是否等于 `P(未来 | x 所在状态)`？
- 若拒绝 H₀ → 检验 H₁：是否匹配某个已有状态？
- 若也拒绝 → 创建新状态
- 多重检验校正：Bonferroni（`alpha / 检验次数`）或 Benjamini-Hochberg

**Phase 3 — 确定化**（`determinization.py`）

确保每个状态-符号对映射到唯一的下一个状态。非确定性状态被分裂直到收敛（最坏：每个后缀一个状态）。移除瞬态（非递归）状态。

**Phase 4 — 度量计算**（`machine.py` + `metrics.py`）

- 构建状态转移矩阵 P → 求解稳态分布 \(\pi\) → 计算：
  - \(C_\mu = H[\pi]\) （统计复杂度）
  - \(h_\mu = \sum_i \pi_i H[\text{emissions} | s_i]\) （熵率）
  - \(E = I[S_t; S_{t+1}]\) （超熵）
  - \(\chi = H[X] - h_\mu\) （预测信息）

**Phase 5 — 可视化**（`visualization.py`）

生成 Graphviz DOT 输出和 (h_μ, C_μ) 复杂度-熵坐标。

### 1.3 验证策略

用三个已知解析解的参考过程验证 CSSR：

| 过程 | 描述 | 预期 C_μ | 预期 h_μ |
|------|------|---------|---------|
| IID 抛硬币 | 无结构 | 0 | 1 bit |
| Even Process | 禁止连续 1（二进制），状态分奇偶 | 1 bit | ~0 |
| Golden Mean Process | 禁止连续 0，需记忆上一个符号 | ~0.69 bit | ~0.69 bit |

### 1.4 L_max 自动估算

```python
def estimate_L_max(N, k):
    if k <= 1: return 1
    L = int(math.log(N) / max(math.log(k), 1e-10))
    return max(1, min(L, 10))
```

### 2.2 行为编码方案（混合编码）

两步编码：

**Step 1 — 推理步骤提取**：Agent 的完整推理链被解析为步骤序列。每个步骤标注：
- **动作类型**（4 类）：`INFER`（推理）、`CALC`（计算）、`VERIFY`（验证）、`CORRECT`（自我修正）
- **结果质量**（4 类）：`CORRECT`、`PARTIAL`（部分对）、`INCORRECT`、`SKIPPED`（跳过）

**Step 2 — 符号生成**：组合为 16 个符号（如 `INFER_CORRECT`、`CALC_INCORRECT`、`VERIFY_SKIPPED` 等）。

编码由 LLM 完成（用专门的分类提示词，从推理 trace 中提取步骤 → 输出符号序列）。

### 2.3 三组对照实验设计

**组 C（Control — 裸 Agent）**：
- 标准系统提示词："你是数学推理助手，逐步思考"
- 每轮 50 题
- 不做任何自我认知注入

**组 B（Baseline — 通用反馈 Agent）**：
- 标准系统提示词 + 通用改进建议（如"检查计算""避免跳步"）
- 反馈由 LLM 生成，但不基于 CSSR 分析
- 反馈长度与组 A 的自我认知报告匹配

**组 A（Experimental — Causal Mirror Agent）**：
- CSSR 分析上轮 50 题的行为序列
- 生成自我认知报告（含因果状态图描述、高频失败模式、C_μ/E/h_μ 度量）
- 报告注入系统提示词
- 下一轮 50 题

**指标**：准确率变化、C_μ/E/h_μ 随时间变化、自我报告的定性质量

### 2.4 实验流程

```
初始化：3 组 Agent（A/B/C）各独立

Round 0（基准）：
  3 组各做 50 题，记录准确率和行为序列
  组 A 额外：CSSR 分析 → 生成自我报告

Round 1-4（各 50 题）：
  组 A：注入上轮自我报告 → 做题 → CSSR 分析 → 新报告
  组 B：注入通用反馈 → 做题
  组 C：继续做题（无增强）

Round N：比较各组准确率趋势
  核心假设：组 A 的改进斜率 > 组 B > 组 C
```

### 2.5 自我认知报告格式

```
# 自我认知报告 — Round N

## 行为度量
- 统计复杂度 C_μ：X.XX bits（内部状态多样性）
- 超熵 E：X.XX bits（行为结构一致性）
- 熵率 h_μ：X.XX bits（每步不确定性）
- 预测信息 χ：X.XX bits

## 因果状态结构
[描述 ε-machine 的主要状态及其转换]

## 关键发现
- 状态 X → 状态 Y 的转换中，错误率显著升高（P(error)=0.78）
- 当跳过验证步骤时，后续失败概率增加
- 有效的自我修正遵循模式 Z

## 建议的改进
[基于因果结构的 2-3 条具体行为调整建议]
```

### 2.6 实验成功的判据

**核心判据**：
- 组 A（Causal Mirror）的准确率提升 > 组 B（通用反馈）> 组 C（无增强）
- 即使 A ≈ B > C，也说明"反馈驱动改进"有效但 CSSR 特异性反馈不比通用反馈好
- 如果 A ≈ B ≈ C，说明当前规模下自我认知无显著作用

**辅助判据**：
- C_μ 和 E 是否随 Round 增加而增加？（行为结构化程度提升）
- h_μ 是否减少？（行为噪声降低）
- ε-machine 的状态结构是否变得更简洁？（更高效的行为组织）

## 风险与缓解

| 风险 | 概率 | 缓解 |
|------|------|------|
| CSSR 在 L_max=3 时需要大量样本（>4000 步）才能做可靠统计 | 中 | 先用合成数据验证 CSSR 正确性；实验从 L_max=1 开始，随轮次累积数据后提升 |
| 行为编码的 16 符号表仍然丢失了关键推理信息 | 中高 | 编码器提示词持续优化；可备选增加语义 token（如"误以为 X=Y"） |
| 自我认知反馈环不稳定（Agent 行为振荡） | 中 | 在报告中加入"保持你做得好的地方"，减少报告注入频率（隔轮而非每轮） |
| LLM API 成本过高（50 题 × 5 轮 × 编码 × 报告 × 3 组） | 中 | 先用 20 题/轮做 pilot；确认可行后扩大 |
| 组 A 和组 B 没有显著差异 | 中高 | 这本身是有价值的负面结果，写分析报告，研究编码粒度/反馈格式的改进方向 |
